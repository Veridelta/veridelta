# DR-02: Quick-start mistakes that name their cause

- **Name.** Quick-start mistakes that name their cause.
- **The promise it proves.** [UC-01](../USERS.md#uc-01-a-first-verdict-on-two-files): a newcomer who makes a mistake learns what to change from the error, without the docs. [UC-04](../USERS.md#uc-04-let-an-agent-run-the-comparison): an agent can act on the error.
- **Definition and formula.** Four mistakes on the quick start path, each run as a configuration, and the count of those whose message names the cause: a `source.path` that does not exist; a Parquet file under a suffix that names no format, such as `.data`, with no `format`; a `primary_keys` column that neither file has; and a `format` value Veridelta does not accept.
- **Unit and window.** Mistakes named, out of four, per release.
- **How it is measured.** Write the four configurations against `tests/fixtures/ci/legacy.csv`, `tests/fixtures/ci/modern_match.csv`, and `docs/assets/data/sample_taxi_data.parquet` copied twice. Run each and read the message:

  ```bash
  uv run veridelta run -c a_missing_file.yaml
  uv run veridelta run -c b_parquet_no_format.yaml
  uv run veridelta run -c c_absent_key.yaml
  uv run veridelta run -c d_unknown_format.yaml
  ```

- **Current value.** Measured 2026-10-06, on the fix for #133 after 0.14.1: 4 of 4. The missing file is named ("The csv file ... does not exist"). The Parquet file with no `format` names its cause ("not among the columns of the source, `legacy.data` read as csv since `format` is not set"). Since the format inference in 0.15.0, a `.parquet` path needs no `format`, so that mistake is a file under a suffix that names none. The message is the same. The absent key names the key and the columns the file holds ("The primary key 'nope' is not among the columns of the source ... The columns read are: 'id', 'status', 'amount'."). The unknown format lists the accepted values. On 0.14.0 the count was 3 of 4: the `.parquet` path failed with the same message as the absent key, which named a symptom.
- **Target, and the reasoning.** 4 of 4. Every mistake on the shortest path has one cause, and the error can say it.
- **What gaming it looks like, and the guardrail against it.** Rewording an error until it reads well without fixing what it reports. The count moves only when the message names the thing to change, and the four runs are the test.
- **What decision changes when it moves.** A mistake below the line is a bug to fix before any feature.
