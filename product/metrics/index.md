# Index

One concept for each key metric, named by its id.

## Metric

- [NS-01](NS-01.md): how many keys a newcomer writes and shell lines they type between a fresh machine and a correct verdict on two files.
- [DR-01](DR-01.md): how many keys the smallest configuration needs before `veridelta run` compares two Parquet files.
- [DR-02](DR-02.md): of four mistakes a newcomer makes on the quick start, how many produce an error that names the cause rather than a symptom.
- [DR-03](DR-03.md): how long a reported wrong verdict, a false match or a false mismatch, stays unfixed in a released version.
- [GR-01](GR-01.md): how many pushdown backends reached the same verdict as a local run on the released version, out of the six the parity suite covers.
- [GR-02](GR-02.md): how many reported false matches or false mismatches are open when a release ships.
- [GR-03](GR-03.md): how many WCAG 2.2 A and AA violations axe-core finds on the docs site and the HTML report.
