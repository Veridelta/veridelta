# Security policy

## Supported versions

Only the latest release on [PyPI](https://pypi.org/project/veridelta/) gets security fixes. A fix ships in the next release, never as a patch to an older one, so upgrade to pick it up.

| Version | Supported |
| :--- | :--- |
| The latest release | Yes |
| Any earlier release | No. Upgrade to the latest. |

## Reporting a vulnerability

**Do not open a public GitHub issue for a security vulnerability.**

If you find one in Veridelta, report it privately through [GitHub's private vulnerability reporting](https://github.com/Veridelta/veridelta/security/advisories/new), or email the maintainers at **veridelta.labs@gmail.com**. We acknowledge a report within 48 hours and give a timeline for triage and a fix. Once the fix is released, we publish a coordinated security advisory and credit the discovery.
